# Your Cozi connector

This repository deployed your private [cozi_mcp](https://github.com/mjucius/cozi_mcp) server to Cloudflare.
You don't need to change anything here. The server installs signed updates by itself.

Don't push to this repository. Cloudflare would rebuild the version it was created with, and your
server would stay on that version until the next release.

Updates, settings, troubleshooting and how to remove everything:
https://github.com/mjucius/cozi_mcp/blob/main/docs/cloudflare-setup.md
